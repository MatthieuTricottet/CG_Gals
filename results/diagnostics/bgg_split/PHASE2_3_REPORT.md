## Implementation notes (please check; none alters a prespecified choice)

1. **Spline (D1 as approved):** `cr(logMstar, df=3, constraints="center")`.
   * The basis is built once per family on pooled rows: 2977 rows at log M★ ≥ 10.5 for Models I/R, and 4328 satellite rows for Model S.
   * The same columns are reused in every per-control fit and every bootstrap draw.
   * **In addition, each basis column is standardised to unit pooled SD.** The unscaled centred basis has one column with SD 0.04. That made its coefficient exceed the `|β| > 20` separation guard in `fit_logistic_model`, which falsely skipped Model S for strong Hα vs RG4 and failed 26 of 50 test bootstrap draws.
   * The scaling is a pure reparametrisation: I checked that the CG estimates and SEs are identical with and without it.
2. **Model R vs Model I identity:** asserted in code. The largest residual over all 18 fits is 4.2e-15.
3. **Bootstrap:**
   * Physical groups are resampled with replacement within each sample (CG4 and the control separately). Model R is refitted with a plain GLM or OLS under the same |β| ≤ 20 guard.
   * Failed draws: 12, 13 and 12 of 2000 for strong Hα (quasi-separation in draws with few CG4 BGG emitters). There were none for the other outcomes. The percentile intervals use the successful draws.
   * **3 CG4 physical groups are also Control4C groups** (the retained host quartets). The analytic cluster SEs treat each as one cluster, while the stratified bootstrap resamples them independently in each stratum, as specified.
4. **Classification:**
   * Codes use the **analytic** cluster-robust 95 % CIs of Model R and the Model I Holm p.
   * A case the rules do not cover (both CIs exclude 0 with the same sign, *and* the interaction is significant) returns `UNMATCHED`. It did not occur.
   * Bootstrap CIs are reported next to the analytic ones but are not used by the codes.
5. **D3 port:** `recent_quenching.morphology_adjusted_models` reproduces the manuscript's hard-coded ORs to every printed digit. `mass_class` gives 0.55 [0.37, 0.81] p = 0.0023 (n = 2582); 0.65 [0.45, 0.95] p = 0.027 (n = 2557); 0.56 [0.30, 1.05] p = 0.072 (n = 399). The `mass_class_satellite` sensitivity gives 0.51, 0.64 and 0.59.

## Discrepancies with the preliminary values (> 1 SE)

* **Model S vs the preliminary 10.0–10.5 satellite proxy: 10 of 12 differ by more than 1 SE** (all except log R_e vs C4C and RG4). **This is an estimand difference, not a code discrepancy:**
  * The proxy refit (satellites at 10.0 ≤ log M★ < 10.5, linear mass term, clusters = physical group) reproduces every preliminary value to ≤ 0.005.
