Data model: galSpecIndx

General description: Index measurements for fibers for which the MPA-JHU spectroscopic parameters pipeline has been run. This file is built out of a similar one in the galspec SVN product. It is designed to be line-by-line matched with the specObj list of all spectra. Any spectra in specObj that do not have a measurement from the MPA-JHU pipeline have all values zeroed out in this file. There is further information about the MPA-JHU results in the parallel files galSpecInfo, galSpecLine, and galSpecExtra. ID values in galSpecInfo are set to -1 for cases where there were no results from the MPA-JHU pipeline. In some cases, the pipeline was run but we don't believe the results are reliable, in which case the column "RELIABLE" in galSpecInfo is set to zero.

Naming convention: galSpecIndx-[DRNAME].fits

Approximate size: 2 Gbytes.

File type: FITS

Read by products: sas

Written by products: sas
