Datamodel: sdss_eboss_firefly

General Description
This page documents the outputs of firefly run on the DR16 SDSS (RUN2D=26) and eBOSS (RUN2D=v5_13_0) spectra. For DR16, the version of firefly used is FIREFLY_VER=v1_1_0 for SDSS and FIREFLY_VER=v1_1_1 for eBOSS.
Naming Convention
eboss_sdss_firefly-RELEASE.fits, where RELEASE=DR16 for the latest release,
